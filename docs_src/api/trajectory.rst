Trajectories
============

These routines extend straight-line motion with annual parallax and lens
orbital motion. Annual parallax accounts for the observer's changing
position as Earth orbits the Sun. The functions use a built-in table of
Earth's positions (an ephemeris), or one you supply. The orbital-motion
functions describe linear, circular, and elliptic lens orbits.
